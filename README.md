# The 12-Week AI-Tutor Guides — catalog site

Static site for the AI-Education catalog: course landing pages, free placement
diagnostics ("score yourself /100"), and the never-used-AI start-here guide.

Generated — do not edit by hand. Pages are built from a private content repo
and published by its `tools/publish_site.sh`. No paid course content is here.

## Blog

Posts are Markdown files in `posts/`. This site is static HTML on GitHub Pages, so the blog is compiled into `blog/` and committed.

```
python3 tools/build_blog.py
```

The command writes `blog/index.html` and `blog/<slug>/index.html`, adds a Blog link to the nav and footer, and adds those URLs to `sitemap.xml`.

To publish a post, add `posts/your-slug.md` with `title`, `description`, `date` (`YYYY-MM-DD`), `slug`, and `summary`, then run the command and commit `posts/`, `blog/`, `sitemap.xml`, and the nav updates. Set `draft: true` in the front matter to leave a file out of the build.

Catalog pages are regenerated by `tools/publish_site.sh` in the private content repo, which overwrites nav and footer edits. After a catalog publish, run `python3 tools/build_blog.py` again so the Blog link, the sitemap entries, and `blog/` come back. Keep `posts/`, `blog/`, and `tools/build_blog.py`.
